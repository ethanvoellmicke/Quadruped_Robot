# Quadruped_Robot
12DOF quadraped robot built from scratch with arduino control, imu stabilization, and RVIZ simulation

# Project Overview
This project includes:

- 12-servo quadruped locomotion
- Arduino-based embedded control
- PCA9685 servo control
- Inverse kinematics
- Gait generation
- IMU-based stabilization
- ROS2 / RViz visualization
- Custom mechanical design and assembly
